# 《散尽千金的人，为什么成了财神？》
# 旁白稿 V1.0

叙述者：60岁陶朱公第一人称

声音要求：
稳重、克制、有阅历，不使用神仙腔。

---

世人拜我求财，却不知道，我最擅长的，是散财。

年轻时，我在越国。

会稽的雨一连下着，城墙、粮仓、军队，都在等一个答案。

那时我先学会的，不是赢，而是等待。

看清局势，认清自己，在该忍的时候忍，在能动的时候再动。

后来越国走出困局，灯火照亮城郭，功名也到了眼前。

可我没有留下。

盛名之下，最难的不是再向前一步，而是知道什么时候应该离开。

我去了齐地，换了名字，耕作、经营。

到陶以后，我不急着问什么最贵。

我看道路，看水路，看季节，也看人真正需要什么。

十九年间，我三致千金，也再散其财。

财富真正考验的，是一个人能不能识时，能不能知止，能不能守信。

所以，今天站在财神面前的你，真正想求的究竟是什么？

是一笔钱，还是驾驭财富的能力？
