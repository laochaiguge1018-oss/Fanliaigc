## 3. 允许与禁止的年龄变化

### 3.1 必须保持不变的身份 DNA

- 长椭圆脸与原有头骨比例。
- 平直眉形；人物自身左眉尾轻微自然断点。
- 眼距与内敛杏形眼的基本轮廓。
- 直鼻梁与圆钝鼻尖。
- 薄唇和窄而有力的下颌。
- 深褐木簪的形制；只允许发髻位置降低。
- 小麦色肤色基线，不美白、不磨皮。

任何一项改变都判定为“换脸”，不是合理老化。

### 3.2 只允许增加的变化

| 参数 | FL45 目标 | 强度边界 |
|---|---|---|
| 面颊 | 比 FL35 略瘦 | 轻度；不凹陷成 60 岁 |
| 鼻唇沟 | 浅、自然 | 静态可见但不能很深 |
| 眼下纹 | 少量浅纹 | 不形成明显眼袋 |
| 太阳穴 | 少量灰白 | 以黑发为主，灰白仅作年龄提示 |
| 发髻 | 比 FL35 更低 | 仍是简朴束髻，不换发式 |
| 上唇须 | 短、整齐 | 不卷翘、不浓密夸张 |
| 下颌须 | 短、整齐 | 不过胸，不连接成长须 |
| 晒痕 | 齐地劳作状态可略加强 | 不改变基础肤色与五官 |
| 体态 | 更松、更稳 | 不驼背、不迟钝 |

### 3.3 禁止变化

- 不重新设计眉、眼、鼻、嘴、下颌或耳位。
- 不增加白眉、长须、仙人感、富商肥态或帝王气。
- 不产生 55–65 岁的明显老化。
- 不使用美容滤镜、塑料皮肤或过度锐化毛孔。
- 不因服装或光线改变人物身份。

## 8. 验收清单

### 8.1 身份闸门（任一失败即退回）

- [ ] 与 FL35 同一长椭圆头骨比例。
- [ ] 人物自身左眉尾断点仍存在，位置未漂移。
- [ ] 眼距一致，眼形只是自然年龄变化。
- [ ] 鼻梁和圆钝鼻尖一致。
- [ ] 薄唇与窄下颌一致。
- [ ] 耳位、发际线和木簪形制没有重新设计。
- [ ] 没有镜像翻转造成左右错误。
- [ ] 匿名观察时能读作约 43–48 岁，而不是 35 岁原样或 60 岁老人。

### 8.2 年龄与毛发

- [ ] 面颊仅略瘦，不明显凹陷。
- [ ] 鼻唇沟与眼下纹为浅纹。
- [ ] 灰发只集中于太阳穴少量区域。
- [ ] 发髻比 FL35 略低，仍使用同一深褐木簪。
- [ ] 上唇须与下颌须短、整齐、不过胸。
- [ ] 无白眉、仙风道骨或富商肥态。

### 8.3 服装状态

- [ ] 三套服装均有独立 `costume_state_id`。
- [ ] 交领右衽方向正确；反打镜头不镜像衣领。
- [ ] 离越装、齐地劳作装、会见使者装不串款。
- [ ] `S04-03`–`S04-06` 服装、袖口和腰带结连续。
- [ ] 衣料为麻、苎麻或克制细织物，无塑料反光。
- [ ] 无珠宝、龙纹、官帽、玉带和夸张纹样。

### 8.4 动作与手部

- [ ] 解绳手指数、关节、绳路和受力正确。

- [ ] 所有离开镜头均不回头。
- [ ] 表演无英雄慢动作、冷笑、愤怒或自满。
