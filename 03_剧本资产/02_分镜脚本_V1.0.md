# 《散尽千金的人，为什么成了财神？》
# 阶段04｜剧本分镜脚本 V1.0

## 制作目标
将4分钟导演剧本拆解为可执行AIGC镜头。

每个镜头包含：
- 镜头编号
- 时间
- 场景
- 人物
- 景别
- 运镜
- 动作
- 声音
- AI视频提示词
- 负面提示词

---

# 第一幕｜悬念
时间：00:00-00:12

## S01-01

场景：财神庙

人物：60岁陶朱公神像

景别：远景→中景

画面：
深夜财神庙，香火散去，空殿清冷，神像位于中央。

运镜：
固定机位，缓慢推进。

声音：
低频钟声、风声、木结构轻响。

AI视频提示词：
深夜古代财神庙，陶朱公神像，香烟缓慢漂浮，烛火轻微晃动，电影级东方历史摄影，固定机位缓慢推进，真实PBR材质。

负面：
现代建筑，LED灯，夸张神光，游戏场景。
